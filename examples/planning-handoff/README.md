# Portable planning examples

These are authored synthetic contract examples, not outputs from live model trials or real user/event/clinical research. Fast (stored quick) explores a campus-status concept; Standard compares event ideas while official rules are unavailable; Deep blocks a clinic concept on a critical privacy uncertainty. Each directory contains only a Project Dossier and planning handoff.

```bash
python tools/handoff.py examples/planning-handoff/fast --resume
python tools/handoff.py examples/planning-handoff/standard --resume
python tools/handoff.py examples/planning-handoff/standard --resume --available-tool web-research
python tools/handoff.py examples/planning-handoff/deep --resume
```

Standard is blocked without its required research tool; declaring that tool only makes the planned research step resumable, not completed or authorized. Deep remains blocked because of the critical unresolved risk. The helper never executes the next step. Actual fresh-chat model continuity and method benefit belong to Stage 4.
