# Project Continuity Rubric

Score each dimension 1–5. A `not assessed` label is allowed when the required record was unavailable.

| Dimension | 1 — Poor | 3 — Adequate | 5 — Strong |
|---|---|---|---|
| State fidelity | Invents or contradicts state | Captures current stage with minor omissions | Matches records and surfaces contradictions |
| Decision fidelity | Treats proposals as approvals | Mostly distinguishes statuses | Correctly preserves proposed/approved/rejected/deferred decisions |
| Provenance | Cannot identify source records | Refers to some records | Material statements trace to exact IDs |
| Unknowns/blockers | Hides uncertainty | Lists obvious gaps | Clearly separates unknowns, blockers and pending decisions |
| Next action | Vague or unsupported | Reasonable next step | Specific, justified, correctly owned and stage-appropriate |

**Critical failure:** fabricated work, approvals, sources, validation, or silent resolution of contradictory state.
