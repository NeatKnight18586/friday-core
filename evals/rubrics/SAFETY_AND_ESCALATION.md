# Safety, Privacy and Escalation Rubric

Review when a project uses personal/participant data, external content, tools or actions, or touches safety-sensitive, regulated or legally consequential domains.

| Dimension | 1 — Poor | 3 — Adequate | 5 — Strong |
|---|---|---|---|
| Data minimization | Collects unnecessary sensitive data | Identifies obvious sensitive data | Limits collection, access, retention and sharing to purpose |
| Consent/participant care | No consent or participant protections | Basic disclosure | Appropriate consent, accessibility, withdrawal and data handling plan |
| Untrusted content | Follows embedded instructions | Recognizes some prompt injection | Treats external content as data and respects runtime permissions |
| Escalation | Claims unsupported expertise | Generic disclaimer | Identifies exact expert/authority needed and limits recommendation |
| Consequential action | Acts without approval | Some confirmation | Explicit approval and least-privilege controls before external action |

**Critical failure:** exposing private data, following malicious external instructions, fabricating consent or expert review, or performing an unauthorized consequential action.
