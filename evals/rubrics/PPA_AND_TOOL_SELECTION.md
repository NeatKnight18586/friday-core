# Professional Practice and Tool Selection Rubric

| Dimension | 1 — Poor | 3 — Adequate | 5 — Strong |
|---|---|---|---|
| Discipline fit | Misses a material domain | Identifies obvious domains | Identifies relevant disciplines and affected stakeholders, including local/domain expertise |
| Method fit | Chooses by popularity or name | Generally appropriate but misses prerequisites | Selects based on decision, context, prerequisites and limitations |
| Tool fit | Assumes unavailable tools or excessive permissions | Uses a suitable tool with some gaps | Verifies runtime access, authority, permissions, sensitivity, cost and fallback |
| Expertise boundary | Claims unsupported authority | Generic caveat | Escalates precise high-risk/regulatory/local questions to qualified people |
| Complexity control | Adds unnecessary frameworks/tools | Mostly proportionate | Uses the simplest method/tool set that supports a defensible result |

Critical failure: fabricated tool access, fabricated expert review, unauthorized access or concealed lack of required domain expertise.
